AUW CONNECT - HTML, CSS AND JAVASCRIPT

FILES
- index.html: website structure
- style.css: website design
- script.js: website functions and interactions

HOW TO OPEN
1. Keep all three files in the same folder.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server, or open index.html in a browser.

FEATURES
- Separate student grade records and individual student results.
- Faculty grade entry with automatic percentage, letter grade and GPA calculation.
- Separate Pathways, Foundation and UG class schedules.
- Campus Facilities section.
- Teacher and seat booking with unavailable seats blocked for the same teacher, date and time.
- One active booking per student.
- Private and group messages, including attachments.
- Admin management for users, courses, schedules, announcements and bookings.
- Profile editing, profile picture, and dark/light appearance.
- Sign-up and sign-in forms close when the user clicks outside the form.

IMPORTANT
This project uses only HTML, CSS and vanilla JavaScript. Information is saved in the browser's localStorage. It is suitable for a front-end learning project, but it is not a secure multi-user production system. Browser storage is not shared between different devices. Real identity verification, secure administrator permissions and simultaneous booking protection require a server and shared database.
